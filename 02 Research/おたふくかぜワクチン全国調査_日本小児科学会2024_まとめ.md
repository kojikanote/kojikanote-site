# 文献まとめ・信頼性評価
## おたふくかぜワクチン接種後の副反応に関する全国調査報告

**発表**: 日本小児科学会予防接種・感染症対策委員会、AMED鈴木班・AMED菅班、国立感染症研究所ほか多施設共同(全38所属機関、著者39名)
**掲載誌**: 日本小児科学会雑誌 第128巻 第1号(2024年)
**研究種別**: 全国前向き観察研究(サーベイランス)
**研究実施主体**: 日本小児科学会

---

## 1. 背景

- 乾燥弱毒生おたふくかぜワクチン(以下、おたふくかぜワクチン)は海外諸国では広く定期接種化されているが、日本では**任意接種**に留まっている
- かつてMMR(麻疹・おたふくかぜ・風疹混合)ワクチンで無菌性髄膜炎の多発が問題となった経緯があり、「より安全性が期待できるワクチンの承認」が定期接種化の前提とされてきた
- 2017年、日本耳鼻咽喉科学会によるムンプス難聴の全国調査結果公表により、ムンプスの疾病負担(合併症)が改めて注目された
  - ムンプス自然感染での合併症頻度:無菌性髄膜炎(1〜10%)、脳炎(0.02〜0.3%)、聴力障害(0.1〜0.25%)、精巣炎(思春期以降発症で20〜40%)
- 2012年5月の予防接種制度見直し第二次提言でも、おたふくかぜワクチンは接種促進が望ましいワクチンの一つに位置づけられている
- 近年は「接種後の無菌性髄膜炎発生は少ない」という臨床現場の意見もあり、多数例での信頼性の高いデータ収集の必要性が指摘されていた

### 本研究の目的
現在国内で承認されている**2種類のワクチン株(星野株・鳥居株)**について、大規模例数での接種後の健康状態を調査し、**無菌性髄膜炎を含む副反応の発生頻度・重篤度を評価**し、定期接種化に関する技術的検討の基礎資料とすること

---

## 2. 方法

### 調査体制
- 専用Webサイト「**Mumps Vaccine Safety Database(Mu-VSD)**」(https://mumps.children.jp)を構築
- 2021年3月21日より日本小児科学会会員へ協力を周知・依頼(郵送・学会誌同封案内・関連団体への通達等、複数回のリマインドを実施)
- 接種期間:**2020年1月1日〜2023年3月31日**
- Mu-VSDへの入力可能期間:2021年3月21日〜2023年6月24日
- 対象:1歳以上就学前の小児(一部6歳の小学1年生を含む)、**保護者によるオプトアウトなし**

### 一次調査
- 協力医(原則、接種医)が接種後**4週間**、**5〜8週間**の時点で保護者へ健康状態を確認しWeb入力
- 収集項目:接種時基本情報(接種日、月齢、性別、接種回数、ワクチンメーカー)、副反応を疑うエピソード(耳下腺炎・顎下腺炎、無菌性髄膜炎、脳炎・脳症、精巣炎・卵巣炎、難聴、急性膵炎)の有無、症状詳細
- **医師が副反応と判断していない場合でも、備考欄に症状記載があれば検討対象に含めた**(過小報告を防ぐ工夫)

### 二次調査
- 一次調査で中枢神経系副反応(無菌性髄膜炎等)が疑われた症例について、保護者の同意のもと症状経過・検査所見・転帰を追加収集
- 症状出現時の残余検体(髄液・血液・便・尿・呼吸器検体)を国立感染症研究所で解析

### ウイルス学的検討
- Real time PCR法(FTD Respiratory pathogens 21、FTD Viral meningitis、FTD Viral gastroenteritisキット)により、インフルエンザ・ライノウイルス・コロナウイルス各種・パラインフルエンザ・RSウイルス・エンテロウイルス・ヘルペス各種・ムンプスウイルスなど多数の病原体を網羅的に検索
- in house系で麻疹・風疹・ムンプスウイルスのゲノム検出、ムンプスウイルス分離培養
- **ワクチン株か野生株かの鑑別**:SH遺伝子領域(560〜728bp)の多様性領域のシークエンス解析

### 報告対象を接種後8週目までとした理由
生ワクチンであるため接種後にワクチン株ウイルスが体内で複製されるが、接種後4〜6週間で被接種者にムンプス免疫が獲得され複製が抑制されることから、**8週目以降の症状はワクチンと無関係と判断される**ため

### 倫理面
- 日本小児科学会倫理委員会(受付番号35-修正-06)、国立感染症研究所生命科学・医学系研究倫理審査委員会(受付番号1548)で承認
- 各施設倫理委員会でも必要に応じ承認、報告医療機関はオプトアウト掲示を実施

## 3. 結果

### 参加規模
- 調査協力登録医師:**919名**(うち1件以上の接種例登録があった医師472名)
- Web登録された被接種例:**62,671例**

### フォローアップ状況
| | 4週間フォロー可能例 | 8週間フォロー可能例 |
|---|---|---|
| 総数 | 59,573例 | 58,783例 |
| 前向きフォロー例(登録後接種) | 45,474例 | 44,708例 |
| 過去接種例(接種後登録) | 14,099例 | 14,075例 |

### 医師が副反応と判断した症状の頻度

| 期間 | 件数 | 頻度(10万接種あたり) |
|---|---|---|
| 接種後0〜4週間 | 460例 | 772例 |
| 接種後5〜8週間(追加分) | 311例 | 529例(0〜8週間で771例) |

- 最も多い症状:**発熱**、次いで感冒症状・上気道炎症状
- 副反応報告頻度は**1歳児の初回接種で最も高かった**
- 医師が副反応と判断しなかったが備考欄に記載のあった症状も同様の傾向(発熱が最多)で、こちらは0〜4週間で516例(10万接種あたり866例)

### 中枢神経系の重篤/特異的症状(最重要所見)

一次調査で中枢神経系の重篤/特異的症状(無菌性髄膜炎、脳炎・脳症、急性小脳失調症)を認めたのは**14例**(表3に詳細)。

**内訳**:
- 無菌性髄膜炎:10例(疑い2例を含む)
- 急性脳炎:1例
- 急性脳症:1例
- 髄膜脳炎:1例
- 急性小脳失調症:1例

- 12例は接種後4週間以内に発症
- 無菌性髄膜炎疑いの1例を除き**全例入院**
- おたふくかぜワクチン株が検出されたと報告された症例:**7例**(うち2例は国立感染症研究所での解析でワクチン株と完全一致を確認、1例は野生株かワクチン株か判別不能)

### 頻度の集計(重要な数値)

| 対象集団 | 疾患 | 頻度 |
|---|---|---|
| 4週間フォロー例(59,573例) | 無菌性髄膜炎(疑い含む)+急性脳炎 | **0.018%(10万接種あたり18.5)** |
| 8週間フォロー例(58,783例) | 無菌性髄膜炎(疑い含む)+急性脳炎+髄膜脳炎 | **0.020%(10万接種あたり20.4)** |
| **前向き8週間フォロー例(44,708例)** | **無菌性髄膜炎(疑い含む)** | **0.013%(10万接種あたり13.4)** ※アブストラクトの数値と一致 |

- 精巣炎・卵巣炎、難聴、急性膵炎の報告は**なし**
- 髄膜脳炎例:退院2ヶ月後の外来で神経学的後遺症なし
- 急性脳炎例:接種8週間後時点でも入院中、リハビリ継続中(要旨執筆時点)

### 接種回数による違い
- **1回目接種後**に発熱・上気道症状などの副反応疑い症状が多く認められた一方、**2回目接種後**の副反応疑い報告は「ほとんど認められていない」
- 無菌性髄膜炎6例(疑いを含む)のうち**5例が1回目接種後**に発生

## 4. 考察:先行研究との比較

| 研究 | 対象 | 無菌性髄膜炎頻度 |
|---|---|---|
| 添付文書(星野株) | - | 0.1%未満(2,300人あたり1人程度) |
| 添付文書(鳥居株) | - | 0.1%未満(1,600人あたり1人程度) |
| Nagai et al., 2007(Vaccine) | 21,465例、前方視的観察研究 | 星野株0.04%、鳥居株0.06% |
| Muta et al., 2015(Vaccine) | Nagaiデータの年齢別再解析 | 3歳未満0.018% vs 3歳以上0.078%(年長児で有意に高い、RR 4.35, 95%CI 1.05-18.2, p=0.04) |
| 中山ら, 2018 | 星野株市販後調査 | 2014年以降、約3万接種に1例以下 |
| Kumihashi et al., 2018 | 鳥居株、医薬品副作用DB(2004-2015年) | 10万接種あたり1.3〜4.4 |
| Ohfuji et al., 2022(Vaccine) | 鳥居株、企業副反応報告 | 10万接種あたり7.90(1998-2000年)→2.78(2016-2018年)に減少 |
| **本研究** | **44,708例、前向き8週間フォロー** | **10万接種あたり13.4** |

- 添付文書引用元のNagai et al.より本研究の頻度が低かった理由:Nagaiらの研究は3歳以上の初回接種児を多く含んでいたため(年長児で頻度が高いというMutaらの知見と整合)
- 一方、市販後調査より高かった理由として、著者らは**任意接種のため市販後調査への報告率自体が低い可能性**、および**本研究のデザイン上、副反応を認めた症例の方が報告されやすい(特に過去接種例)というバイアスの可能性**を挙げている

### 著者らの結論
- 頻度は低いものの、ワクチン株が検出された症例で急性脳炎やけいれん重積を認めた例が報告されている点は留意すべき
- **1回目接種を実施する際は、特に髄膜炎・脳炎/脳症などの中枢神経症状に注意が必要**
- ムンプス罹患後の難聴は予後不良でリスクが大きいため、おたふくかぜワクチンは小児にとって重要なワクチンであるとしつつ、一定の副反応リスクも認め、**家族との十分な相談のうえでの意思決定支援**の重要性を強調

---

## 5. 本研究の限界(著者らが明記した点)

1. 報告医療機関が調査期間中の**全接種例を登録できたか確認する手段がない**ため、正確な発生頻度の算出は困難
2. ムンプス関連の主要病名以外は自由記載のため、**因果関係が明らかでない症状・事象も報告に含まれている**
3. インターネット接続できない医療機関では報告しにくい
4. **自発的参加による報告医による調査**であり、全接種例への確認は困難(選択バイアスの可能性)
5. 国内承認済みの**星野株・鳥居株のみ**の結果であり、海外株には外挿できない

## 6. 信頼性についての評価

### 強み
- **極めて大規模な症例数**(登録62,671例、前向き8週間フォロー44,708例)であり、この分野における日本国内最大級の前向きサーベイランスの一つ
- **ウイルス学的な裏付け**(PCR、シークエンス解析によるワクチン株/野生株の鑑別)を伴っており、単なる症状報告に留まらず病因診断の精度が高い
- 医師が副反応でないと判断した症例も備考欄記載があれば検討対象に含めるなど、**過小報告(under-reporting)を防ぐ設計上の工夫**がなされている
- AMED研究班・国立感染症研究所という公的研究機関が関与し、倫理審査(学会・国立感染研双方)を経ている
- 先行研究(Nagai 2007、Muta 2015、Kumihashi 2018、Ohfuji 2022)との比較を通じて、自らの結果を相対化する姿勢がとられている

### 限界・注意点
- **後方視的登録(過去接種例)と前向きフォロー例が混在**しており、特に過去接種例では重篤な症例ほど登録されやすいという報告バイアスが生じている可能性を著者ら自身が認めている(実際、過去接種例からの重篤な中枢神経系副反応の報告が複数含まれる)
- **自発的な協力医療機関による調査**であるため、母集団としての代表性(全国のワクチン接種全体を反映しているか)には限界がある
- 症状の重症度判定や「副反応と判断するか否か」が**報告医個人の裁量に委ねられている**部分が大きく、実際に考察内でも「1歳児の発熱や皮膚症状は、副反応ありと判断された場合となしと判断された場合でほぼ同じ発生割合だった」ことから、**判定基準のばらつき**が示唆されている
- 対照群(非接種群)を伴わない観察研究であるため、報告された症状のうちどこまでが真にワクチンに起因するものか(自然発生率との比較)は本研究単独では判別できない
- 無菌性髄膜炎の頻度推定において、**先行研究間でも0.04%〜0.1%未満まで大きな幅**があり、本研究の値(0.013%)がこの範囲の中でどう位置づけられるかは、対象年齢構成や報告体制の違いに大きく左右される点に留意が必要

### 総合評価
| 項目 | 評価 |
|---|---|
| 研究デザイン | 大規模前向き観察研究(全国サーベイランス)、対照群なし |
| サンプルサイズ | 非常に大きい(前向き例で44,708例) |
| バイアスの可能性 | 報告バイアス(特に過去接種例)、自発的協力医療機関による選択バイアスの可能性を著者らも明記 |
| 病因診断の精度 | 高い(PCR・シークエンスによるワクチン株同定) |
| 先行研究との整合性 | 概ね整合(添付文書より低め、一部市販後調査より高め、年齢による違いも先行研究と一致) |
| 臨床的意義 | 高い(国内での定期接種化検討に向けた基礎資料としての位置づけが明確) |

**まとめ**として、本研究は症例数・ウイルス学的検討の精度の両面で、日本におけるおたふくかぜワクチンの安全性評価として現時点で最も質の高いデータの一つと言えます。特に「1回目接種後、特に1歳児での接種で中枢神経系副反応(無菌性髄膜炎等)のリスクに注意が必要」という知見は、定期接種化の議論において重要な実務的示唆を持ちます。一方で、報告バイアスの可能性や対照群の不在という観察研究に共通する限界があるため、**頻度の絶対値そのものよりも、年齢・接種回数による相対的な傾向(1歳児1回目接種でリスクが高い、2回目以降はほとんど副反応報告がない)を重視して解釈するのが妥当**と考えられます。
